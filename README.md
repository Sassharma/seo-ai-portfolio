# 🔴 Sahil Sharma — SEO & AI Portfolio

A premium black/red portfolio website inspired by modern AI agency landing pages.

## Features
- Futuristic red/black visual system
- Responsive layout
- Animated-style globe hero
- SEO skills/services
- Featured SEO dashboard
- Skills & tools section
- Nebula AI chat interface
- Smooth navigation
- No framework required

## Run
Open `index.html` directly in your browser.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, then:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**

## Important
The statistics in the design are demonstration UI values, not verified real-world results.
